## 2026-09-30 - Alt Text in Markdown Interfaces
**Learning:** In markdown-only repositories, the README acts as the primary user interface. Finding opportunities like empty alt text in banner images `![]()` improves accessibility for screen readers navigating the documentation.
**Action:** Next time working in a markdown-heavy or markdown-only project, proactively search for unlabelled images (`!\[\]`) and add descriptive alt text as a low-effort, high-impact accessibility win.
