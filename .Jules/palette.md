## 2024-10-03 - Descriptive Alt Text for Markdown UI

**Learning:** In markdown-only projects (like documentation or instruction repositories), images serve as critical UI elements. When images lack descriptive alt text, they are inaccessible to screen readers, degrading the overall user experience and accessibility of the content.

**Action:** Always verify that informative and decorative images in markdown files contain appropriate alt text (`![Description](url)` instead of `![](url)`). Treat markdown as a primary user interface that requires the same accessibility standards as HTML elements.
