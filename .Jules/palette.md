## 2024-05-24 - Accessibility in Markdown-Only Repositories

**Learning:** In markdown-only repositories, the documentation itself serves as the primary user interface. Standard UX and accessibility improvements, such as providing descriptive alt text for informative and decorative images, must be applied directly to the markdown elements.

**Action:** When working on markdown-heavy or markdown-only projects, treat the documentation as the UI. Ensure all images have descriptive alt text and all links are descriptive to maintain accessibility standards.
